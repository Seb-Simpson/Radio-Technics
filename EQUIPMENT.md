## Questions for the station engineer

### Mixing console
- Make and model?
- Which channel/fader is assigned to each source (presenter mic, guest mics, Myriad, other inputs)?
- Are there controls presenters should never change?

### Microphones
- How many guest microphones are there?
- Make and model of each microphone?
- Which console channel is each connected to?
- Do microphones need a separate on/off or mute control?

### Myriad
- Which version is installed, and on which computer/screen?
- Which playout modes does the station use (e.g. automatic, manual/live assist)?
- Can presenters also advance to the next song from the Myriad screen? If so, how?

### Green button
- How is the button connected to Myriad (wiring and trigger mechanism)?
- What does it do in each Myriad playout mode?
- What happens if it is pressed more than once?
- Is there any indicator that a press was received?

### Zoom video camera
- Does "Zoom" refer to the manufacturer or to Zoom video calls?
- Make and model? What is it used for (recording, streaming, calls)? What is it connected to?

### Headphones
- How many headphone outputs are there and where?
- Which control sets each headphone's volume? Is there a separate headphone amplifier?

### Studio speakers
- Make and model?
- Do the speakers mute automatically when a microphone is live?
- Which control sets the speaker volume?

### Level meters
- Which audio does each meter show (on-air output, microphone, Myriad…)?
- What level should presenters aim for?

### Equipment rack
- What equipment is installed?
- Should presenters ever touch anything in the rack?
- What do normal indicator lights look like?

### Studio computers
- How many computers are there and what is each used for?
- Which one runs Myriad?
- May presenters restart any computer, and how?

### General
- Technical-support contact details (who, how, and out-of-hours arrangements).
- Is there an existing emergency procedure for silence on air?
- Which photographs show which equipment (to place hotspots in RT-002)?
